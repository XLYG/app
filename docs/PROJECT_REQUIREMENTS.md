# 项目开发需求

## 项目目标

开发一个基于 React Native + Expo 的 AI 学习助手 App。

用户可以在 App 中提交用户名和 DeepSeek API Key，输入学习问题，由 App 请求后端，后端从 MySQL 读取配置后代为请求 DeepSeek，并把结果返回给 App 展示。

## MVP 范围

第一阶段只做最小可运行版本：

1. 一个聊天首页。
2. 一个 API 配置页，用于提交用户名和 DeepSeek API Key。
3. 用户可以输入问题。
4. App 可以把问题发送给后端。
5. 后端使用用户保存的 DeepSeek API Key 请求 DeepSeek。
6. App 可以显示后端返回的 AI 回复。
7. 用户可以删除已保存的 DeepSeek API Key。
8. App 可以展示加载中、失败、未配置等基础状态。

## 暂不开发

以下内容先不做，避免项目一开始变复杂：

1. 登录、注册、找回密码。
2. 用户中心。
3. 会员、支付、订阅。
4. 多智能体、多会话管理。
5. 云端聊天历史。
6. 复杂动画和复杂主题系统。
7. 直接在前端请求 OpenAI、Claude、DeepSeek 或其他模型供应商。
8. 前端直接连接 MySQL。

## 核心用户流程

1. 用户打开 App。
2. 如果没有配置后端信息，引导用户进入设置页。
3. 用户填写用户名和 DeepSeek API Key。
4. 用户回到聊天页。
5. 用户输入学习问题并点击发送。
6. App 显示用户问题和加载状态。
7. 后端读取 MySQL 中保存的 DeepSeek API Key，向 DeepSeek 请求回复。
8. 后端返回回复后，App 展示 AI 回复。
9. 用户可以在配置页删除已保存的 DeepSeek API Key。
10. 如果请求失败，App 显示可理解的错误提示。

## 成功标准

MVP 完成时，应满足：

1. 新手可以清楚知道每个文件负责什么。
2. 项目可以通过 Expo 正常启动。
3. 聊天流程可以从输入到展示回复完整跑通。
4. 用户名和 DeepSeek API Key 可以通过后端保存到 MySQL 并再次读取使用。
5. 错误状态不会让 App 崩溃。
